# Contributing

KYN is intended to be built in public. Issues and proposals should identify the
affected invariant, threat, user benefit, privacy impact, compatibility impact, and
test evidence. Changes to live semantics require an exact versioned operator decision
and cannot be inferred from discussion, popularity, or merged code alone.

Do not submit real participant data, relationship evidence, credentials, secrets,
private security reports, or campaign-restricted material. Synthetic fixtures must
be visibly fictional and noncorrelatable to real people.

The contribution license and final code-of-conduct process remain pending release
decisions. Contributions cannot be accepted for distribution until those terms are
published.
